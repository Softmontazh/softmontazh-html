# Софтмонтаж — сайт softmontazh.kz

Статический сайт ТОО «Софтмонтаж» (слаботочные системы, Караганда). Без сборки и фреймворков: HTML + CSS + немного JS.

## Структура
```
index.html, services.html, certificates.html, contact.html   страницы
assets/css/site.css     стили сайта
assets/js/site.js       общие шапка и подвал (меню, телефон, ссылки правятся здесь), мобильное меню, копирование реквизитов, просмотр сертификатов
assets/certificates/    сертификаты в WebP (полный размер и превью)
assets/img/             значок платформы Esemer
brand/                  фирменный стиль: логотипы, фавиконы, значки разделов, превью для соцсетей, colors.css (см. brand/README.md)
sitemap.xml, robots.txt
```

## Как править
- Пункты меню, телефон, WhatsApp, ссылки — в начале `assets/js/site.js`.
- Цвета — `brand/site/colors.css`, вёрстка — `assets/css/site.css`.
- Новый сертификат: положить `<имя>.webp` и `<имя>-thumb.webp` в `assets/certificates/` и добавить карточку в `certificates.html`.

Сайт открывается и локально (двойной клик по index.html), и на хостинге.

## Деплой (сервер)
Сайт лежит на VPS вместе с esemer.kz: папка `/var/www/softmontazh.kz` — клон этого репозитория (ветка `main`), nginx отдаёт статику.

Обновить сайт после изменений в GitHub (main):
```
sudo bash /var/www/softmontazh.kz/deploy/update.sh
```
Вернуть предыдущую версию:
```
sudo bash /var/www/softmontazh.kz/deploy/update.sh --rollback
```
- Журнал версий: `/var/www/softmontazh-releases.log` (дата · было · стало).
- Конфиг nginx хранится в `deploy/nginx.conf`; скрипт сам ставит его, если он изменился (с копией старого и проверкой `nginx -t`).
- Наружу не отдаются: `.git`, `*.md`, `*.sh`, `deploy/`, `VERSION`.
- Кэш: страницы — `no-cache`, css/js/картинки — 30 дней. После правки css/js увеличить `?v=N` в ссылках на всех страницах.
- Ограничения: сайт до ~50 МБ, картинки в WebP, видео в репозиторий не класть.

## Каталог оборудования (`/catalog/`)
Каталог дистрибьютора Barlau (Hikvision, Ruijie и др.) с розничными ценами. Серверная часть — Django в папке `app/`
(тот же стек, что у платформы Esemer), база — PostgreSQL `softmontazh`, сервис `softmontazh` на `127.0.0.1:8002` за nginx.
```
app/catalog/models.py     товары, бренды, разделы, настройки, журнал загрузок
app/catalog/importer.py   загрузка выгрузок Barlau: Excel (цены, остатки, картинки) + YML (описания)
app/catalog/views.py      страницы /catalog/, /catalog/<товар>/ и API /api/catalog/...
app/catalog/admin.py      админка /admin/
assets/js/catalog.js, assets/css/catalog.css   внешний вид каталога
deploy/catalog-install.sh, softmontazh.service, softmontazh-catalog.cron, softmontazh-manage
```
- **Установка (один раз):** `sudo bash /var/www/softmontazh.kz/deploy/update.sh`, затем `sudo bash /var/www/softmontazh.kz/deploy/catalog-install.sh`.
  Дальше всё (сайт и каталог) обновляет `update.sh`: бэкап базы → миграции → перезапуск сервиса → проверка.
- **Данные:** выгрузки забираются по ссылкам каждые 6 часов (`/etc/cron.d/softmontazh-catalog`), кнопка «Обновить из Barlau сейчас» — в админке, раздел «Загрузки из Barlau».
  Картинки не храним — берутся по ссылкам с b2b.barlau.kz. Если в новой выгрузке меньше половины позиций — загрузка отменяется, на сайте остаётся прежнее.
- **Цены:** розница Barlau ± наценка (общая → бренд → раздел, ближайшая побеждает), округление; у товара можно задать свою цену. Всё — в админке.
- **Команды:** `sudo softmontazh-manage createsuperuser` (вход в админку), `sudo softmontazh-manage import_barlau` (загрузить сейчас).
- **Бэкапы:** `/opt/softmontazh/backups` — ночные (7 шт.) и перед каждым обновлением (5 шт.). Каталог восстанавливается и из выгрузки Barlau.
- **Ограничения сервера:** 1 воркер, `MemoryMax=200M`; импорт читает файлы потоково.
- **Локально:** `cd app && pip install -r requirements.txt && python manage.py migrate && python manage.py import_barlau --excel файл.xlsx && python manage.py runserver` (SQLite, открыть http://127.0.0.1:8000/catalog/).

### Закупка, пол и менеджеры
- **Закупка** = розница Barlau − «Моя закупка: скидка от розницы, %». Скидка задаётся у бренда, раздела или любого подраздела дерева (админка → «Дерево разделов (скидки закупки)»); действует ближайшая к товару. У товара можно вписать точную закупку.
- **Пол для менеджера** = закупка + «мин. наценка, %» (общее правило в «Настройках каталога», своё — у бренда/раздела/подраздела), не выше цены на сайте. У товара можно задать свой пол. Нет закупки — нет пола: менеджер продаёт только по рознице.
- **Менеджеру, % от прибыли** — так же по уровням; считается со сделки (появится с корзиной/КП).
- **Менеджер в админке:** Пользователи → добавить → «Статус персонала» + группа «Менеджер». Видит только товары: цену на сайте, пол, «можно уступить», наличие. Закупку, маржу, настройки и дерево скидок не видит.
